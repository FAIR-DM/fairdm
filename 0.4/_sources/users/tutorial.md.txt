# Create your first dataset

In this tutorial you create a project, create a dataset inside it, describe the dataset and credit a colleague on it. You finish with a private dataset that has an abstract and two people credited. The tutorial does not add samples or measurements, because the portal has no screen for creating them.

## Before you start

You need:

- the address of a FairDM portal
- an account on it, or the means to make one (see [How to create an account](account/create-an-account.md))
- a colleague who already has a profile on the portal, whom you can find on the [People](community/people.md) screen

## 1. Sign in

1. Open the portal. If you are not signed in, you see the [Home](home.md) screen with its large welcome heading.
2. Select **Sign in** under the buttons at the top of the screen.
3. Enter your email address and password on the [Sign in](account/sign-in.md) screen, then select **Sign In**.

You arrive on a screen headed **My Dashboard**, with a greeting under the heading such as `Welcome, Ada!`, where `Ada` is your first name.

## 2. Create a project

A project groups related datasets. See [The core data model](../explanation/the-core-data-model.md) for how projects, datasets and records fit together.

1. In the bar at the top of the screen, select **Create new**, then **Project**.
2. In **Project name**, type `My first project`.
3. In **Status**, choose **In progress**.
4. In **Visibility**, choose **Private**, so that only people you give access to can open it while you learn.
5. Select **Save & continue**.

The new project's page opens. Its heading is `My first project`. A badge beside the heading reads **In progress**, and a notice above it begins **This project is private.**

## 3. Create a dataset in the project

1. Select **Create new**, then **Dataset**.
2. In **Name**, type `My first dataset`.
3. Select the **Project** field and start typing `My first`. Choose **My first project** from the list.
4. Leave **License** as the portal offers it.
5. In **Visibility**, choose **Private**.
6. Select **Save & continue**.

The dataset's page opens. Its heading is `My first dataset`, with a **Private** badge beside it and the notice **This dataset is private.** above it. The **Details** card on the right names `My first project` next to **Project**.

## 4. Add a description

1. In the **About** card, select **Write a description**.
2. On the **Descriptions** screen, find the **Abstract** box and type a sentence or two about what the dataset will hold.
3. Select **Save & continue**.

The dataset's page opens again, with a message that begins **Saved**. The card that was titled **About** is titled **Abstract** and shows your text. See [Why complete metadata matters](../explanation/why-complete-metadata-matters.md) for why the other description areas exist.

## 5. Credit a colleague

1. Select **Contributors** in the strip of page links near the top of the page.
2. On the **Contributors** screen, select **Add person**. The list under **People** shows you, because the portal credited you when you created the dataset.
3. On the **Add a person** screen, stay on the **Already in the portal** tab. In **Search the people in this portal**, type your colleague's name and select **Search**.
4. Select **Choose** beside your colleague's name.
5. Under **Their affiliation for this dataset**, leave the choice the portal selected, then select **Add to this dataset**.
6. On the **Edit a contributor** screen, under **What they may do on this dataset**, choose **Can edit**, then select **Save**.

The **Contributors** screen opens again with a message ending **was saved.** Your colleague appears under **People** with a **Can edit** badge beside their name. See [How access to a record is decided](../explanation/how-access-to-a-record-is-decided.md) for what each level allows.

## What you have created

You have a private project holding a private dataset. The dataset has an abstract, and you and a colleague are credited on it.
