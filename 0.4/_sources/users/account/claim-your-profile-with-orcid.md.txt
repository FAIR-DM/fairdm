# How to claim your profile with ORCID

This guide takes over a profile that was made for you before you had an account, so the work already credited to you becomes part of your account. You do it by signing in with the ORCID iD that the profile holds.

## Before you start

The profile must hold your ORCID iD and must still be unclaimed. To check, find the profile on the [People](../community/people.md) screen and open it. An unclaimed profile shows a notice that begins **This profile was created so**, and a badge reading **Unclaimed profile**. If the profile does not hold your ORCID iD, ask the portal's administrators to correct it first.

## Steps

1. Open the [Sign in](sign-in.md) screen.
2. Select **ORCID**.
3. On the page headed **Sign In Via ORCID**, select **Continue**.
4. Sign in at ORCID with the ORCID iD the profile holds, and authorise the portal to read it.
5. When the portal returns you with a page headed **Sign Up**, check your email address and **Display name**, then select **Sign Up**.

## The result

The profile is your account. Open it from the [People](../community/people.md) screen. The badge reads **Claimed profile** where it read **Unclaimed profile**, the notice has gone and the credits that were already on the profile are listed under **Projects** and **Datasets**. See [Your profile](your-profile.md).

If the profile does not change, see [How to fix a profile that will not claim](fix-a-profile-that-will-not-claim.md). For why the portal only trusts an ORCID iD on an unclaimed profile, see [How a profile is claimed](../../explanation/how-a-profile-is-claimed.md).
