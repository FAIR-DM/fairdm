{% extends "overview/page.html" %} {% load i18n humanize fairdm thumbnail contact %} {% comment %} The measurement's own page, drawn from the base Measurement model and what the registry says about the measurement's type. A reuser asks four things of a single measurement: what the result was, how it was measured, what it was measured on, and whether they can cite and reuse it. The page answers them in that order. The anatomy and the facts column come from `overview/page.html`; the context is gathered by the measurement `Overview` plugin. A measurement type adds its own content by providing `/_overview.html`, which extends this template and fills its blocks: {% extends "measurement/measurement_overview.html" %} {% block overview.result %}…the type's own result…{% endblock %} {% block overview.properties %}…{% endblock %} Measurement blocks: overview.result (in the figures' place; shown when the type declares a `value`, otherwise the block a type fills first), then in the wide column overview.properties (empty here), overview.procedure, overview.notes, overview.sample, overview.siblings; in the facts column, overview.location (the sample's map, when it has a location and is visible). What the registry says about the type opens from the type badge in the header.
