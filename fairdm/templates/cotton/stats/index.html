{% comment %} — daisyUI `stats`: several figures read as one group. daisyUI lays stats out in one row and scrolls sideways when they don't fit. `cols` and `lg` switch it to a wrapping grid instead, so four figures sit two-by-two on a phone and in one row on a desktop. The prebuilt stylesheet ships no responsive `stats-horizontal`, and daisyUI's own `grid-auto-flow: column` would override the column count, so the flow is reset inline. Attributes: cols – grid columns below `lg` (1–4); unset keeps daisyUI's single row lg – grid columns from `lg` up (1–6) class – extra classes on the root Candidate for django-mvp. {% endcomment %}
