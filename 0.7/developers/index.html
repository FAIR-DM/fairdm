    Developers¶

    This section is for you if you build a research data portal on FairDM and deploy it. You define your community’s sample and measurement types, configure and extend the portal’s pages, and run it in production. If you are new, start with the tutorial. How-to guides take you through one task each, reference pages describe the settings, models, components and APIs, and the explanation covers why parts of FairDM work as they do. Explanation every reader needs is in the shared explanation.
