    fairdm.contrib.contributors.services.registries¶

    Look people up in ORCID and organizations up in ROR, and make profiles from what is found.

    Initialization

    seconds_to_wait(retry_after)¶

    Read a Retry-After header, which is a number of seconds or an HTTP date.

    Args: retry_after: The header’s value, or None when it was not sent.

    Returns: The whole seconds to wait, never negative, or None when the value says nothing.

    fetch_record(address, headers=None)¶

    Fetch one registry record for a profile, uncached, as the sync and the transforms do.

    Every fetch of a record to store on a profile goes through here, so all of them share one timeout and one reading of a refusal. Retrying is the caller’s: the sync task retries with a growing delay, or after the wait a 429 asks for.

    Args: address: The record’s address. headers: Request headers.

    Returns: The decoded record, or None when the registry answers 404.

    Raises: RegistryRateLimited: The registry answered 429. requests.RequestException: The request failed or the answer was another error. ValueError: The answer was not JSON.

    exception RegistryUnavailable¶

    Bases: Exception

    Signal that a registry could not be asked or its answer could not be read.

    Raised for a network error, a timeout, an answer that is not a success and an answer that is not in the form the registry documents.

    Initialization

    Initialize self. See help(type(self)) for accurate signature.

    exception SearchLimitReached¶

    Bases: fairdm.contrib.contributors.services.registries.RegistryUnavailable

    Signal that a person has searched the registries more often than they may in a minute.

    Initialization

    Initialize self. See help(type(self)) for accurate signature.

    count_search(user)¶

    Count one registry search against a person, refusing it past the limit.

    The count is kept in the default cache for the minute it began in, so it is shared by every process and forgotten after a minute.

    Args: user: The signed-in person searching.

    Raises: SearchLimitReached: The person has made SEARCHES_PER_MINUTE searches this minute.

    ask(address, parse, *, params=None, headers=None, missing_ok=False)¶

    Request an address from a registry and read its answer, unless it is kept.

    What a registry answers is kept for KEPT seconds in the default cache, under the address, the parameters and the active language, since an answer is read into text in that language. “There is no such record” is an answer and is kept. A failure is not, so the next request asks again.

    Args: address: The address, which no search term is ever part of. parse: A function that turns the decoded answer into what the caller wants. params: Query parameters, which requests encodes. headers: Request headers. missing_ok: Whether a 404 is an answer (“there is no such record”) rather than a failure.

    Returns: What parse returns, or None for a 404 when missing_ok is true.

    Raises: RegistryUnavailable: The request failed, the answer was not a 200, or parse could not read it.

    class Orcid¶

    Search ORCID for people, fetch one record, and make a profile from it.

    A record is a dictionary with id and shown_id (the ORCID iD), name, given, family, employer (the first current employer, or an empty string) and detail (what tells namesakes apart).

    SEARCH¶

    ‘https://pub.orcid.org/v3.0/expanded-search/’

    RECORD¶

    ‘https://pub.orcid.org/v3.0/{}/record’

    ACTIVITIES¶

    ‘https://pub.orcid.org/v3.0/{}/activities’

    identifier_in(text)¶

    Pick an ORCID iD out of text that is one, or an address of one.

    Args: text: A search term or an identifier.

    Returns: The bare iD, or None when the text is not in the form of one.

    static words_of(text)¶

    Return the words of a name or an organization, with nothing ORCID’s query language reads.

    Args: text: A name or an organization.

    classmethod all_words(field, words)¶

    Return a clause needing every word in field, the last one possibly typed in part.

    Args: field: The ORCID field to search. words: The words the field must contain.

    queries_for(term, affiliation='')¶

    Return the fielded queries a name search tries in turn, the strictest first.

    ORCID reads a bare term against every field of a record and joins its words with OR, so a name alone finds thousands of unrelated people. Each query here asks the name fields only: first the name as typed, as a phrase, then every word of it in any order with the last word as a prefix, so a name still being typed or given family name first is found. An affiliation narrows each query to people with an organization of that name on their record.

    Args: term: The name searched for. affiliation: Part of the name of an organization on the person’s record.

    Returns: The queries, none when the term has no words.

    search(term, affiliation='')¶

    Search by name, or by iD when the term is one.

    Args: term: A name, an ORCID iD or the address of one. affiliation: Part of the name of an organization on the person’s record, to narrow a name search.

    Returns: {"results": [...], "more": bool}: at most RESULTS_SHOWN records of people with a public name, and whether the registry holds more matches than that.

    Raises: RegistryUnavailable: ORCID could not be asked or answered badly.

    results_from(body)¶

    Read a search answer, leaving out records with no public name.

    Args: body: The decoded answer of the search.

    Returns: The results and the flag, as search returns them.

    found_in(entry)¶

    Shape one search result.

    Args: entry: One item of the answer’s expanded-result.

    Returns: The record, or None when the person has no public name.

    record_of(orcid_id, given, family, employer, place='')¶

    Shape a person for the templates, or return None when there is no name.

    Args: orcid_id: The bare ORCID iD. given: The given names, possibly empty. family: The family name, possibly empty. employer: The name of the current employer, possibly empty. place: Where the employer is, possibly empty.

    Returns: The record, or None when both names are empty.

    fetch(identifier)¶

    Fetch one person’s public record.

    An identifier that is not in the form of an ORCID iD is refused before any request is made.

    Args: identifier: The bare ORCID iD, or its address.

    Returns: The record, or None when the identifier is malformed, ORCID has no such record, or the record has no public name.

    Raises: RegistryUnavailable: ORCID could not be asked or answered badly.

    read_record(orcid_id, body)¶

    Read a record answer: the public name and the first current employer.

    Args: orcid_id: The iD that was asked for. body: The decoded answer.

    Returns: The record, or None when the person has no public name.

    known(record)¶

    Find the person the portal already holds under the record’s ORCID iD.

    Args: record: A record from search or fetch.

    Returns: The person, or None.

    profile(record)¶

    Return the person the portal holds under the iD, or make one.

    A person made here has the name and the iD, no email address, an unusable password and no account.

    Args: record: A record from search or fetch.

    Returns: The person.

    AFFILIATION_SECTIONS¶

    (‘employment’, ‘education’, ‘qualification’, ‘invited-position’, ‘membership’, ‘service’)

    The sections of an ORCID record that name an organization the person belongs or belonged to, in the order they are offered when nothing else separates them.

    affiliations(orcid_id)¶

    Return every organization on a person’s public ORCID record.

    All the affiliation sections are read, ended ones included, each organization once. ORCID identifies an organization by its ROR ID, or by a Funder Registry, Ringgold or GRID ID, and the last three are resolved to a ROR ID through ROR.

    Args: orcid_id: The bare ORCID iD.

    Returns: One dictionary per organization, current ones first, then the most recently ended: name, ror (its ROR ID, or an empty string when none could be found) and current. Empty when ORCID could not be reached.

    static ror_for(source, value)¶

    Return the ROR ID of an organization ORCID identifies another way, or an empty string.

    Args: source: The kind of identifier ORCID gives, such as FUNDREF. value: The identifier.

    affiliations_from(body)¶

    Read the affiliation sections of an activities answer.

    Args: body: The decoded answer.

    Returns: One dictionary per entry: name, source and value of the identifier ORCID gives (ror holds the bare ROR ID itself when that is the source), current, the year it ended and the section’s rank.

    class Ror¶

    Search ROR for organizations, fetch one record, and make a profile from it.

    A record is a dictionary with id (the ROR address), shown_id (the address without its scheme), name (ROR’s display name) and detail (its kind and where it is).

    SEARCH¶

    ‘https://api.ror.org/v2/organizations’

    RECORD¶

    ‘https://api.ror.org/v2/organizations/{}’

    identifier_in(text)¶

    Pick a ROR ID out of text that is one, or an address of one.

    Args: text: A search term or an identifier.

    Returns: The bare ID, or None when the text is not in the form of one.

    search(term)¶

    Search by name, or by ID when the term is one.

    Args: term: A name, a ROR ID or the address of one.

    Returns: {"results": [...], "more": bool}: at most RESULTS_SHOWN active organizations, and whether the registry holds more matches than that.

    Raises: RegistryUnavailable: ROR could not be asked or answered badly.

    results_from(body)¶

    Read a search answer, leaving out organizations that are not active.

    Args: body: The decoded answer of the search.

    Returns: The results and the flag, as search returns them.

    record_of(item)¶

    Shape one organization for the templates, or return None when it cannot be chosen.

    Args: item: An organization as ROR describes it.

    Returns: The record, or None when the organization is not active or has no display name.

    fetch(identifier)¶

    Fetch one organization’s record.

    An identifier that is not in the form of a ROR ID is refused before any request is made.

    Args: identifier: The bare ROR ID, or its address.

    Returns: The record, or None when the identifier is malformed, ROR has no such record, or the organization is not active.

    Raises: RegistryUnavailable: ROR could not be asked or answered badly.

    known(record)¶

    Find the organization the portal already holds under the record’s ROR ID.

    Args: record: A record from search or fetch.

    Returns: The organization, or None.

    profile(record)¶

    Return the organization the portal holds under the ID, or make one.

    An organization made here has the name and the ID.

    Args: record: A record from search or fetch.

    Returns: The organization.

    EXTERNAL_IDS¶

    None

    The ways ORCID identifies an organization other than by its ROR ID.

    resolve(source, value)¶

    Find the ROR ID of an organization another registry identifies.

    ORCID names many organizations by their Funder Registry, Ringgold or GRID ID. ROR lists the identifiers it knows for an organization, so a search on one finds it. An identifier that no organization holds, or that several do, finds nothing.

    Args: source: The registry as ORCID names it: FUNDREF, GRID or RINGGOLD. value: The identifier, in the form ORCID gives it.

    Returns: The bare ROR ID, or None.

    Raises: RegistryUnavailable: ROR could not be asked or answered badly.

    sole_id_from(body)¶

    Read the ROR ID of the one active organization an identifier search found.
