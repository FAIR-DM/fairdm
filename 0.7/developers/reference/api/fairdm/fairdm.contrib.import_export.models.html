    fairdm.contrib.import_export.models¶

    The stored records of an import: one job per file and one row per row of it.

    Module Contents¶

    API¶

    import_file_path(instance, filename)¶

    Name the stored file of an upload by a random key, never by what it was called.

    Args: instance: The ImportJob the file belongs to. filename: The name the file was uploaded with.

    Returns: imports/ and a random 32-character key followed by the file’s extension in lower case. The upload’s own name stays in ImportJob.filename.

    class ImportJob(*args, **kwargs)¶

    Bases: django.db.models.Model

    A file uploaded into one dataset under one import definition.

    The job runs from upload to outcome. The check, the import and the undo all run in the background. The check writes nothing to the dataset and keeps the outcome of every row as an ImportRow. The import writes the same rows and keeps what undoing it would restore.

    get_absolute_url()¶

    Give the address of the job’s page under its dataset.

    Returns: The address.

    property definition¶

    The import definition the file was read with.

    Returns: The definition, or None when the portal no longer has one of that name.

    property model¶

    The sample or measurement model the rows fill.

    Returns: The model class of the definition.

    property type_name¶

    The plural name of the type the file holds.

    Returns: The model’s plural verbose name as text.

    property is_running¶

    Whether a background task is working on the job.

    Returns: True while the job is being checked, imported or undone.

    property is_finished¶

    Whether the job has an outcome and nothing more happens to it.

    Returns: True once the job is imported, undone, discarded or failed.

    property writes¶

    How many records the import writes.

    Returns: The number of rows added plus the number updated.
