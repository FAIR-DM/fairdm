scoped_view(view_class, scope)#

Return the subclass of a record view that serves one scope.

django-tomselect rebuilds a view as view_class() when it validates a value, so the scope has to be an attribute of the class and cannot be an argument of as_view().

Args: view_class: The record view to subclass. scope: One of "public", "view" or "edit".

Returns: A subclass of view_class with scope set. The same class for the same arguments.

class LimitedAutocompleteMixin#

Attributes: page_size: The results in a page. A request cannot change it. max_pages: The last page that is served. max_query_length: The longest search text. class RecordAutocompleteView(**kwargs)#

Bases: fairdm.contrib.autocomplete.views.LimitedAutocompleteMixin, django_tomselect.autocompletes.AutocompleteModelView

Offer the records of one kind that the person searching may reach at one scope.

Attributes: scope: "public" offers public records to everyone. "view" adds the records the person may view. "edit" offers only the records the person may edit. "profile" offers the records one person, the owner, is credited on: their private ones only to them. Fixed by the address and never read from the request. noun_plural: The kind’s name in the plural, for the headings of the groups. exact_lookups: Lookups on which an exact match is offered first. prefer_param: The request parameter that names a relation and a value, as dataset=5. Records that match come first, in a group of their own. It orders and groups, and never adds or removes a record. preferred_heading: The heading of the preferred group, with %(things)s standing for the kind’s name in the plural.

offered(user, *, owner=None, type=None, depends_on=None)#

Return the records this scope offers a person, before any search or page.

Args: user: The person searching, or an anonymous user. owner: The person whose records the profile scope offers, as a person or a primary key. Other scopes ignore it. type: A registered sample or measurement type to keep, or None for every type. depends_on: Lookups the records must match, such as {"dataset": 5}, when the field chooses within another field’s value. Each lookup must be one the view allows a request to filter on.

Returns: A queryset of the records the scope offers that person.

Returns: The owner’s records, private ones included only when user is the owner. Nothing when there is no such person.
