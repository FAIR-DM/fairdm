class SampleDatasetListFilter(field, request, params, model, model_admin, field_path)#

Bases: django.contrib.admin.RelatedFieldListFilter

A dataset list filter offering every dataset, private ones included.

The stock filter reads through Dataset’s privacy-first default manager, so for a portal whose datasets are still private it would offer no choices and never render.

Initialization

class SampleChildAdmin(model: type[polymorphic.admin.childadmin._ModelT], admin_site: Any, *args: Any, **kwargs: Any)#

Bases: polymorphic.admin.PolymorphicChildModelAdmin

Base admin for sample child models, with inlines for their related records.

Subclass it for each sample type and set base_model. Declare base_fieldsets rather than fieldsets so the polymorphic admin can add the subclass’s own fields.
