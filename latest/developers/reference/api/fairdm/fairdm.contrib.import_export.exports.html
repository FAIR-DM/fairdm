    fairdm.contrib.import_export.exports¶

    Write the rows of a record type as a file.

    An export writes exactly the columns the type’s table schema lists, so a file that goes out can come back in.

    Module Contents¶

    Classes¶

    ExportFormat

    One file format an export can be written in.

    TableExport

    Writes the rows of one record type in any export format.

    Functions¶

    format_for

    Find a format by its key.

    Data¶

    SHEET_NAME_LIMIT

    The most characters Excel allows in a sheet’s name.

    FORBIDDEN_IN_SHEET_NAME

    The characters Excel does not allow in a sheet’s name.

    SAMPLE_COLUMNS

    The columns that name a sample, written only for a sample the viewer may open.

    BYTE_ORDER_MARK

    What starts a CSV file so Excel reads it as UTF-8.

    MIN_VALIDATED_ROWS

    The fewest rows of a column a list validation covers.

    SPARE_VALIDATED_ROWS

    How many rows past the data a list validation covers.

    EXPORT_FORMATS

    Every format, in the order the menu lists them.

    API¶

    SHEET_NAME_LIMIT¶

    31

    The most characters Excel allows in a sheet’s name.

    FORBIDDEN_IN_SHEET_NAME¶

    ‘compile(…)’

    The characters Excel does not allow in a sheet’s name.

    SAMPLE_COLUMNS¶

    (‘sample_name’, ‘sample’)

    The columns that name a sample, written only for a sample the viewer may open.

    BYTE_ORDER_MARK¶

    ‘\ufeff’

    What starts a CSV file so Excel reads it as UTF-8.

    MIN_VALIDATED_ROWS¶

    5000

    The fewest rows of a column a list validation covers.

    SPARE_VALIDATED_ROWS¶

    1000

    How many rows past the data a list validation covers.

    class ExportFormat¶

    One file format an export can be written in.

    Attributes: key: The short name the address and the menu use. label: What the menu calls the format. hint: The menu’s one-line note about the format. content_type: The response’s content type. extension: The file name’s extension.

    key: str¶

    label: str¶

    hint: str¶

    None

    content_type: str¶

    None

    extension: str¶

    EXPORT_FORMATS: tuple[fairdm.contrib.import_export.exports.ExportFormat, ...]¶

    ()

    Every format, in the order the menu lists them.

    format_for(key: str) → fairdm.contrib.import_export.exports.ExportFormat | None¶

    Find a format by its key.

    Args: key: The format’s key, such as csv.

    Returns: The format, or None when no format has the key.

    class TableExport(schema)¶

    Writes the rows of one record type in any export format.

    Attributes: schema: The type’s table schema, which decides the columns.

    Initialization

    Keep the schema the files are written under.

    Args: schema: The type’s table schema.

    rows(queryset)¶

    Write each record as a row of cells.

    The records are read in chunks, so a large table is never held in memory. A measurement’s sample is named only when its sample_open annotation is true.

    Args: queryset: The records, in the order the rows should come out.

    Yields: A list of cells, one per column, for each record.

    response(queryset, key, filename_stem)¶

    Write the records as a file download.

    Args: queryset: The records to write. key: The key of one of EXPORT_FORMATS. filename_stem: What the file’s name starts with, before its extension.

    Returns: The response, with the format’s content type and a file name made from the stem, in any script.

    Raises: ValueError: When no format has the key.

    workbook(rows=())¶

    Write an Excel workbook of the rows, a column guide and the allowed values.

    Every string is written as text, so a name that starts with = is never a formula.

    Args: rows: Any iterable of rows of cells, none for an empty file.

    Returns: The workbook’s bytes.

    sheet_title(name, taken)¶

    Make a name Excel accepts for a sheet and no other sheet has.

    Args: name: The name wanted. taken: The names already used. The new one is added to it.

    Returns: The name without the characters Excel forbids, cut to 31 characters, with (2) and so on before the cut when another sheet has it.

    write_text(sheet, row, column, value)¶

    Write a cell as text, never as a formula.

    Control characters a spreadsheet cannot hold are left out.

    Args: sheet: The worksheet. row: The cell’s row, from 1. column: The cell’s column, from 1. value: The value to write.

    Returns: The cell.

    write_data(sheet, rows)¶

    Write the headings, their notes and the rows.

    Args: sheet: The first worksheet. rows: The rows of cells.

    Returns: How many rows were written.

    note_for(column)¶

    Write the note that sits on a column’s heading.

    Args: column: The column.

    Returns: The label, the kind and unit, how to write it, whether it is needed and what it holds.

    write_allowed(sheet, data, count)¶

    Write the allowed values and the list validations that use them.

    Args: sheet: The worksheet of allowed values. data: The worksheet of rows, which gets the validations. count: How many rows the data sheet holds.

    write_guide(sheet)¶

    Write the column guide: a line about the portal ID and a row per column.

    Args: sheet: The guide’s worksheet.
