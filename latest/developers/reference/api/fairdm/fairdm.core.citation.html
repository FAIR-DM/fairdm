    fairdm.core.citation¶

    A record’s citation as a value, and the BibTeX and RIS files written from it.

    The value knows nothing of the database or of a request: the overview plugins build a Citation from a record, and the formats are written from the value alone.

    escape_tex(value)[source]¶

    Write a value so BibTeX reads it back as typed.

    Whitespace runs become one space. \, $ and ^ become their TeX commands. Braces are paired by order in one left-to-right pass: a { closed by a later } is written \{ and \}, every other brace as \textbraceleft{} or \textbraceright{}. The characters latexcodec escapes, inside pybtex’s writer, are left to it.

    Args: value: The text to escape.

    Returns: The escaped text.

    classmethod from_contributor(contributor)[source]¶

    Read a FairDM contributor as the text citation names it.

    Args: contributor: A person or an organisation credited on the record.

    Returns: Family and given name for a person with both, else the contributor’s own name as one literal, as fairdm.core.overview.author_name writes it.

    classmethod from_item_name(name)[source]¶

    Read a literature.Name from a data publication.

    Args: name: The publication’s name, as django-literature stores it.

    Returns: The literal name, or the family name with its non-dropping particle in front, the given name with its dropping particle after, and the suffix.

    to_bibtex_person()[source]¶

    Write the name as a pybtex person.

    Returns: A pybtex.database.Person. A literal name is one braced last name, so BibTeX never splits it.

    to_ris()[source]¶

    Write the name as an RIS author.

    Returns: “Family, Given, Suffix”, or the literal name.
