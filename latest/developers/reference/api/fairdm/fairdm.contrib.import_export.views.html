    fairdm.contrib.import_export.views¶

    Views for importing and exporting dataset records, publishing, and package downloads.

    Module Contents¶

    Classes¶

    BaseImportExportView

    Base view for importing and exporting a dataset’s records with django-import-export.

    DataImportView

    Import records from an uploaded spreadsheet into the current dataset.

    DatasetPublishConfirm

    Ask the user to confirm publishing a dataset.

    DataExportView

    Download the current dataset’s records, or an empty template, in the chosen format.

    DatasetPackageDownloadView

    Download a dataset and its metadata as a ZIP package.

    MetadataDownloadView

    Download a dataset’s DataCite metadata as XML.

    TableSchemaView

    Download the Frictionless Table Schema of a type’s file, open to everyone.

    UploadForm

    Form with a single field for an uploaded file.

    API¶

    class BaseImportExportView(**kwargs)¶

    Bases: django.views.generic.FormView

    Base view for importing and exporting a dataset’s records with django-import-export.

    Attributes: from_encoding: Encoding used to read uploaded text files. model: The model whose records are imported and exported. form_class: The form class, set by subclasses. success_url: Where to send the user after success, set by subclasses. import_kwargs: Default keyword arguments for the import.

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    from_encoding¶

    ‘utf-8-sig’

    model¶

    None

    form_class¶

    None

    success_url¶

    None

    import_kwargs¶

    None

    get_context_data(**kwargs)¶

    Add the formats, the data type, the import result and which error details to show.

    property export_formats¶

    Map each export format’s title to its format class.

    property import_formats¶

    Map each import format’s title to its format class.

    dispatch(request, *args, **kwargs)¶

    Resolve the model being imported or exported before handling the request.

    get_resource()¶

    Return the resource for the resolved model, bound to the current dataset.

    Returns: An instance of the model’s registered resource class.

    get_resource_model()¶

    Resolve the model class named by the type query parameter.

    Without a type the first registered sample model is used.

    Returns: The model class for the requested type.

    Raises: ValueError: No models are registered, or type matches none.

    get_resource_qs()¶

    Return the current dataset’s records of the resolved model.

    Returns: A queryset filtered to the current dataset.

    get_dataset_format(file)¶

    Choose the import format from the uploaded file’s extension.

    Args: file: The uploaded file.

    Returns: An instance of the matching import format.

    Raises: ValueError: The extension matches no import format.

    result_has_errors(result, form)¶

    Re-render the form with the import errors listed.

    Args: result: The failed import result. form: The submitted form.

    Returns: The rendered response.

    form_invalid(form)¶

    Re-render the invalid form.

    get_import_kwargs()¶

    Return the keyword arguments passed to the resource’s import, for subclasses to customise.

    Returns: A copy of import_kwargs.
