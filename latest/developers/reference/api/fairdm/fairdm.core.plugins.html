    API¶

    class OverviewPlugin(**kwargs)¶

    Bases: fairdm.contrib.plugins.Plugin, fairdm.views.FairDMTemplateView

    Reusable overview plugin for displaying object details.

    This base class provides a standard overview/detail view for any model. Portal developers can inherit from this and customize:

    • menu: Configure tab label, icon, and order

    • template_name: Override the template (or use hierarchical resolution)

    • get_context_data(): Add custom context variables

    • permission: Set required permission for access

    Attributes: page_lead: The line under the page title. page_icon: The icon shown beside the page title. menu: The tab label, icon and order.

    Example: ```python from fairdm import plugins from fairdm.core.plugins import OverviewPlugin

    @plugins.register(Sample)
class SampleOverview(OverviewPlugin):
    menu = {"label": "Overview", "icon": "eye", "order": 0}
    template_name = "samples/sample_overview.html"

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context["measurements"] = self.base_object.measurements.all()
        return context
```

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    class CitationFile(**kwargs)¶

    Bases: fairdm.contrib.plugins.Plugin, django.views.View

    One format of a record’s citation as a file, at <record>/cite/<format>/.

    The record’s overview answers who may open it, and this view asks that overview, so a private record answers a stranger as its page does and an unknown record is not found. The file is the format’s value on the overview’s own context, so it is the one the Cite panel shows.

    A portal plugin that sets its own extra_views must list this class to keep the addresses.

    Attributes: name: The route’s name, <namespace>:overview-citation. url_path: The route’s last part, cite/<format>.

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    name¶

    ‘citation’

    url_path¶

    ‘cite/str:format’

    setup(request, *args, **kwargs)¶

    Build the overview that owns this address, set up for this request.

    has_permission()¶

    Ask the owning overview, so the file opens for whom the page opens for.

    handle_no_permission()¶

    Answer as the owning overview answers.

    get(request, *args, **kwargs)¶

    Answer with the citation in the format named by the address.

    Args: request: The request. *args: Positional URL arguments. **kwargs: Keyword URL arguments, the record’s and the format.

    Returns: The file, as an attachment named after the record.

    Raises: Http404: The format is not one of FORMATS.

    class RecordOverviewPlugin(**kwargs)¶

    Bases: fairdm.core.plugins.OverviewPlugin

    The overview of a project, dataset, sample or measurement.

    Holds what every one of those pages works out the same way: who is credited, the People panel, identifiers, citation, timeline, licence entry, records by type and the charts. A portal changes one piece of a page by subclassing that page’s plugin and overriding one of these methods.

    Attributes: people_named: How many credits the People panel names, with their roles. people_faces: How many faces it draws after them before it counts the rest. resolvable_identifier_types: The identifier types that link to doi.org.

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    get_context_data(**kwargs)¶

    Add what the shared page reads on every record.

    The People panel’s link to the Contributors tab, each panel’s Edit link, the word for the record’s kind, and the record’s image, which fills the header’s trailing side.

    get_contributions() → list[fairdm.contrib.contributors.models.Contribution]¶

    List the record’s credits, people first and then organizations, each in order.

    Everything an overview or a citation names comes from this list, so they follow the order the team set on the Contributors tab. select_related stops at the polymorphic base, which has neither a person’s name parts nor a way to tell the two apart, so the real instances are fetched in one extra query.

    Returns: The record’s contributions, each with its real contributor, roles prefetched.

    static get_role_uris(contribution) → set[str]¶

    Give the addresses of the roles held on one credit.

    Args: contribution: A contribution, from :meth:get_contributions.

    Returns: The addresses of its roles.

    static get_contributors_with_role(entries, role, *, cited_only=False) → list[fairdm.contrib.contributors.models.Contributor]¶

    Pick out the contributors credited with one role.

    Args: entries: The record’s credits, from :meth:get_credits. role: The address of the role. cited_only: Leave out anyone whose credit keeps them out of the citation.

    Returns: The contributors of every entry that holds it.

    get_credits() → list[dict[str, Any]]¶

    List everyone credited on the record.

    Each contributor is its own type (person or organisation). The affiliation is the one recorded on the credit itself, so a person credited with no organization has none.

    Returns: One {"contributor", "roles": {address: label}, "affiliation", "cited"} entry per credit, in the order of :meth:get_contributions. cited is False for a person the credit leaves out of the citation.

    get_people(entries=None) → dict[str, Any]¶

    Work out what the People panel shows: names with roles first, then faces.

    Args: entries: The record’s credits, when the caller already has them. Defaults to :meth:get_credits.

    Returns: named: the first people_named credits, each with its contributor, its first two roles, how many more_roles it holds and its affiliation. faces: the next people_faces contributors. more: how many are left after those. total: everyone credited.

    get_identifiers() → list[dict[str, Any]]¶

    List the record’s identifiers for the fact sheet.

    A DOI or an IGSN links to doi.org, since an IGSN is a DataCite DOI since 2023. A legacy IGSN handle, which does not start with 10., does not resolve there and stays unlinked.

    Returns: One {"type", "value", "link"} entry per identifier, type being the identifier type’s concept. link is None for any other type.

    static get_primary_identifier(identifiers) → dict[str, Any] | None¶

    Pick the identifier a reader looks for first: the first one that resolves.

    Args: identifiers: The record’s identifiers, from :meth:get_identifiers.

    Returns: The first identifier with a link, or None when none resolves.

    get_publisher() → str¶

    Name the publisher a citation gives: the site’s name.

    Returns: The current site’s name, or an empty string when the site has none.

    static format_cited_names(names) → str¶

    Write cited names as a citation lists them, like :func:format_authors.

    Args: names: The :class:~fairdm.core.citation.CitedName values, in order.

    Returns: “Keller, A., Oliveira, T. & Brandt, L.”, or an empty string for no names.

    get_citation(*, authors, year, title, link, publisher=None) → str¶

    Write the citation in DataCite’s form: Creators (Year). Title. Publisher. Identifier.

    Args: authors: The creators to name, as contributors or as cited names. year: The year of publication. title: The record’s title. link: Its DOI link, or the address of the page. None when it has none. publisher: The publisher to name. Defaults to :meth:get_publisher.

    Returns: The citation as plain text.

    build_citation(*, authors, year, title, link, publisher=None, types=('misc', 'GEN')) → fairdm.core.citation.Citation¶

    Gather the parts of the record’s citation into the value the files use.

    Args: authors: The creators, as contributors or as cited names. year: The year of publication. title: The title. link: The link the text ends with, or None. publisher: The publisher. Defaults to :meth:get_publisher. types: The BibTeX and RIS types.

    Returns: The citation, keyed by the record’s portal ID. Its DOI is set when link is a doi.org link.

    get_citation_formats(citation, text) → list[dict[str, Any]]¶

    List the ways to take the citation, for the Cite panel and the files.

    Args: citation: The :class:~fairdm.core.citation.Citation. text: The citation as text.

    Returns: One {"key", "label", "value", "url", "download"} entry per format, in the order of FORMATS. url is the format’s address beside the record’s page, or None where the portal’s plugin does not mount :class:CitationFile.

    Args: key: The format’s key, one of FORMATS.

    Returns: The address, or None when the portal’s plugin does not mount :class:CitationFile.

    get_cited_details(citation, text) → dict[str, Any]¶

    Give the two keys every record’s citation card adds to its text.

    Args: citation: The :class:~fairdm.core.citation.Citation. text: The citation as text.

    get_timeline(steps, dates, descriptions, entries) → list[dict[str, Any]]¶

    Join the three ways the vocabularies describe a step in a record’s life.

    A step combines a date type, a contributor role and a description type. Dated steps come first in date order, undated ones after them in the order given. A date recorded only to the year or the month is shown as recorded, never padded out to a day.

    Args: steps: [(date_type, role, description_type, label)], each type and role given by its address. dates: The record’s dates, keyed by the address of their type. descriptions: The record’s descriptions, keyed by the address of their type. entries: The record’s credits, from :meth:get_credits.

    Returns: One {"label", "date", "day", "people", "note"} entry per step with anything to show.

    get_license_entry(licence, note=None) → dict[str, Any]¶

    Write the fact sheet’s licence entry: the licence linked to its text, or a warning.

    Args: licence: The licence, or None when none is chosen. note: A line to show under the licence.

    Returns: An entry for :class:c-overview.sheet.

    get_type_mix(samples, measurements) → dict[str, Any] | None¶

    Count the records by type for the bars in each type’s colour.

    Args: samples: The samples to count. measurements: The measurements to count.

    Returns: samples and measurements, each [(plural type name, count)] largest first, and max, the largest count, which every bar is drawn against. None when there is nothing to count.

    get_sample_points(samples) → dict[str, Any]¶

    Give the located samples as GeoJSON for the map to draw.

    The rows are read with values(), never as model instances, so the answer costs one query however many samples there are.

    Args: samples: The samples to draw. Those without a location are left out.

    Returns: A FeatureCollection with one Point feature per located sample, ordered by name. Each feature’s properties are name, type (the sample type’s name, empty when the type’s model no longer exists), dataset (the dataset’s name) and url (the sample’s page).

    get_sample_map(samples, coverage, points_url, *, count_datasets=False) → dict[str, Any] | None¶

    Work out what the map panel shows: how many samples are located and where.

    One aggregate query counts the samples, no rows are read.

    Args: samples: The samples the page counts. coverage: The smallest box holding their locations, or None. points_url: The address that answers the located samples as GeoJSON. count_datasets: Whether to count the datasets the located samples come from.

    Returns: located, missing (the samples without a location), bounds (the coverage as [west, south, east, north], with east carried past 180 when the box crosses the 180th meridian so MapLibre fits the narrow box), area (the coverage as text) and points_url, plus datasets when asked. With no located sample, bounds and area are None. None when samples is empty.

    get_growth_chart(samples, measurements) → dict[str, Any] | None¶

    Draw the cumulative samples and measurements by month, two series on one count axis.

    Args: samples: The samples to count. measurements: The measurements to count.

    Returns: The chart and its text alternative, or None when the records span fewer than two months.

    class SamplePoints(**kwargs)¶

    Bases: fairdm.contrib.plugins.Plugin

    Answer a record’s located samples as GeoJSON, for its overview page’s map.

    It decides nothing itself. The owning overview plugin says who may open the record and which of its samples the viewer sees, so this address answers exactly as the record’s page does: a private record is “not found”, and the points are the samples the page counts.

    The owner is built with this mount’s model. A plugin built without it resolves no record, and a plugin that resolves none lets everyone in.

    Attributes: owner: The overview plugin that owns this address, set when access is decided.

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    name¶

    ‘sample-points’

    url_path¶

    ‘sample-points’

    owner¶

    None

    has_permission() → bool¶

    Ask the owning overview plugin whether the viewer may open its record.

    handle_no_permission()¶

    Refuse as the overview does, so a private record answers “not found”.

    Give the samples the page counts that have a location, as GeoJSON.

    class TypedOverviewPlugin(**kwargs)¶

    Bases: fairdm.core.plugins.RecordOverviewPlugin

    The overview of a record portals subclass: a sample or a measurement.

    Two things differ from a project or dataset overview.

    The template follows the record’s type. For each concrete class from the record’s own type up to base_model, it looks for <app_label>/<model_name>_overview.html, then falls back to fallback_template. A type gets its own page by providing that template, extending its record’s template and filling the overview.* blocks it wants. A subtype inherits its parent type’s page until it provides its own.

    The record follows its dataset. It opens for everyone once its own dataset is public and published, and otherwise only for people who hold a level on the record, or on its dataset or that dataset’s project (visible_to). Anyone else gets a 404, so the address never confirms the record exists. PrivateRecordNotFoundMixin can’t be reused here: it reads obj.open_to_everyone, which samples and measurements don’t have.

    Initialization

    Constructor. Called in the URLconf; can contain helpful extra keyword arguments, and other things.

    base_model¶

    fallback_template¶

    None
