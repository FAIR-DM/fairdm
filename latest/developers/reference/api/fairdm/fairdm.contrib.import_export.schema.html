fairdm.contrib.import_export.schema#

The columns of a record type’s file, worked out from its configuration.

Nothing here is written per type. A sample or measurement type that is registered gets its columns from the model and its configuration each time they are asked for:

  • the identifiers first: the portal ID (portal_id) and the Local ID,

  • the name, and for a measurement the sample it was made on,

  • the type’s own fields, in the order the model declares them,

  • the fields every sample or measurement has: status and the four location columns.

When the configuration lists resource_fields only those are offered, plus the identifiers and whatever a new record cannot be saved without.

class Column#

One column of a type’s file.

Attributes: name: The heading an export writes and a template carries. It is the model field’s name and is never translated. label: What the column is called on screen. kind: How its cells are read: a key of KIND_LABELS. role: key (the portal ID), match (the Local ID), field or export (written on export, ignored on import). required: Whether a new record needs a value. description: What goes in it. attribute: The model attribute it fills, or None. model_field: The model field behind it, or None. unit: The unit numbers are given in. allowed: For a list, (value, meaning) pairs. The value is what a cell holds. max_length: The most characters a text cell may hold. decimals: The most decimal places a number may have. minimum: The smallest number allowed. maximum: The largest number allowed. example: A value as a cell would hold it. aliases: Other headings the column is recognised by. group: Which part of the guide it belongs to: ids, own or shared.

build_table_schema(config) → fairdm.contrib.import_export.schema.TableSchema#

Work out the columns of a sample or measurement type.

Nothing is read from the type’s own table, so a stored record, and who may see it, never changes the result. Only the vocabularies a concept column lists are queried.

Args: config: The type’s ModelConfiguration.

Returns: The type’s table schema.

Return the columns every type starts with.

Returns: The portal ID, the Local ID and the name, and for a measurement its sample and that sample’s name.
