class FairDMVisibilityFilter#

Bases: rest_framework.filters.BaseFilterBackend

Queryset-level visibility filter for FairDM API list endpoints.

Restricts list querysets to objects the requesting user can see:

  • Projects and datasets with visibility=PUBLIC are always included. Samples and measurements are included when their dataset is public and published: a public dataset that is not published shows its own record and keeps its data back.

  • Records the user holds at least the view level on, directly or from the dataset or project above, are also included. Rows that django-guardian stores for a project, dataset, sample or measurement grant nothing.

  • For any other model, records where the user holds a stored guardian ‘view’ permission.

Both sets are combined in one query to avoid N+1 queries.

For models with no known visibility mechanism (such as Organization), the filter returns the full queryset, making all records publicly accessible. The people list leaves accounts out in its own queryset. Override filter_queryset() in a viewset subclass for stricter filtering.

This replaces ObjectPermissionsFilter from djangorestframework-guardian, which requires explicit guardian entries for all objects and so hides publicly-visible records that have no guardian permission rows.

class ChangedSinceFilterSet(data=None, queryset=None, *, request=None, prefix=None)#

Bases: django_filters.FilterSet

Narrows a list to the records changed after, and before, a moment.

Each value is an ISO 8601 date or date-time, compared with the record’s modified time as given. A date alone means the start of that day, and a time without an offset is read in the portal’s time zone. A value that cannot be read is refused with a 400 naming the parameter.

class IdentifierFilter(*args, **kwargs)#

Bases: django_filters.CharFilter

Narrows a list to the contributor that holds an identifier.

The value is an identifier as stored, such as an ORCID iD, or the address it resolves to: the address of a known scheme is taken off the front, with or without a trailing slash and with http or https. A value is also matched with its spaces removed, as an ISNI is written in groups of four and stored without them.

class FairDMFilterBackend#

Bases: django_filters.rest_framework.DjangoFilterBackend

Django-filter backend that gives every list its changed-since filters and its parents.

Every list takes modified_after and modified_before. A sample list also takes its dataset, and a measurement list its dataset and sample.

The filters a registered type declares match related records by database number, and are shared with the portal’s own pages. Here every relation filter matches by short identifier, a number is refused, and a filter on a relation with no identifier is left out.
