    class Measurement(*args, **kwargs)¶

    Bases: fairdm.core.abstract.BasePolymorphicModel

    A record of a specific observation or calculation made on a sample.

    A polymorphic model: domain-specific measurement types inherit from this base. Subclasses should define value and optionally uncertainty fields for get_value() and print_value() to work.

    Attributes: CONTRIBUTOR_ROLES: The roles a contributor can hold on a measurement. DESCRIPTION_TYPES: The description types a measurement can carry. DATE_TYPES: The date types a measurement can carry. objects: The manager, with the MeasurementQuerySet helpers. dataset: The dataset this measurement belongs to. uuid: Unique short identifier with an m prefix. contributors: Generic relation to contributor records. sample: The sample on which the measurement was made. local_id: The creator’s own identifier for the measurement within its dataset. location: The point where the measurement was made, in WGS 84. location_elevation: Metres above mean sea level. location_uncertainty: Metres within which the true place lies.

    get_value()¶

    Return the measurement value, with its uncertainty when there is one.

    A type is not obliged to nominate a pint quantity for value, so uncertainty arithmetic is only attempted where the value supports it.

    Returns: The value with its plus_minus uncertainty applied when both exist and the uncertainty can be applied, the plain value otherwise, or the name when the class defines no value (the base class).

    print_value()¶

    Return the value and its uncertainty as a string for a person.

    Delegates to the framework’s quantity formatter, which renders a pint Measurement as “value ± error unit”, rather than building a string by hand.

    Returns: The formatted value.

    effective_location_for(user=None)¶

    Return where the measurement is for a viewer: its own location, else its sample’s.

    The sample’s is used only where the viewer may open the sample, by the same rule as MeasurementQuerySet.with_effective_location.

    Args: user: The viewer, or None for a visitor who is not signed in.

    Returns: An EffectiveLocation naming the point, its elevation and uncertainty and whose location it is, or None when the viewer has none to be shown.

    get_absolute_url()¶

    Return the URL of the measurement’s own detail page.

    class VocabularyGuardedSave¶

    Refuse a type outside the record’s own collection, even on a direct save.

    A concept field checks its collection only in full_clean(), which a manager’s create() and a bare save() never call. Subclasses set VOCABULARY_NOUN for the error message.

    Attributes: VOCABULARY_NOUN: The noun in “‘x’ is not a valid Measurement type.”
