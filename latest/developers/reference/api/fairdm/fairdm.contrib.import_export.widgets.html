    fairdm.contrib.import_export.widgets¶

    The widgets that read and write the cells of a type’s file.

    Each kind of column has one widget over import_export.widgets.Widget. clean turns a cell into the value a model field stores and render turns a stored value into a cell, so a value written by render is read back by clean as the same value. A cell that cannot be read is refused with a ValueError and a reason, which django-import-export turns into an error on the row.

    class SampleCellWidget(column, dataset=None, user=None)¶

    Bases: fairdm.contrib.import_export.widgets.CellWidget

    A sample by portal ID, or by Local ID or name within the dataset.

    Every lookup reads the samples the person may see, so a sample they may not see is refused with the words used for one that does not exist. Each distinct cell is looked up once and the answer kept, so a file of many rows over a few samples asks the database a few times. A widget serves one file.

    Attributes: dataset: The dataset the file is imported into. user: The person importing, or None for a visitor. found: The sample or the refusal each cell read so far came to, by its text.

    Initialization

    Keep the column, the dataset and the person.

    Args: column: The column whose cells the widget reads and writes. dataset: The dataset the file is imported into. user: The person importing, or None for a visitor.

    clean(value, row=None, **kwargs)¶

    Read a sample cell.

    Args: value: The cell as the file gave it. row: The row the cell is in. **kwargs: What django-import-export passes on.

    Returns: The sample, or None for an empty cell.

    Raises: ValueError: When no sample the person may see has the portal ID, and none in the dataset has the Local ID or name, or when the Local ID or name is shared by several samples.

    look_up(text: str) → fairdm.core.sample.models.Sample¶

    Find the sample a cell names among those the person may see.

    Args: text: The cell’s text.

    Returns: The sample.

    Raises: ValueError: When no sample the person may see has the portal ID, and none in the dataset has the Local ID or name, or when the Local ID or name is shared by several samples.

    render(value, obj=None, **kwargs)¶

    Write a sample as its portal ID.

    Args: value: The sample. obj: The record the value belongs to. **kwargs: What django-import-export passes on.

    Returns: The portal ID.
