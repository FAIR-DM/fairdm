    fairdm.contrib.import_export.reader¶

    Reading a file into headings and rows.

    Module Contents¶

    Classes¶

    FileReader

    Turns the bytes of a CSV, TSV, Excel or OpenDocument file into rows.

    API¶

    exception FileProblem(message, code)[source]¶

    Bases: Exception

    A file that cannot be imported, with the reason a person can act on.

    Args: message: The reason, in the active language. code: A short name for the reason: format, too_large, too_large_unpacked, unreadable, empty, no_rows or too_many_rows.

    Attributes: code: The short name of the reason.

    Initialization

    Keep the reason and its short name.

    class FileReader[source]¶

    Turns the bytes of a CSV, TSV, Excel or OpenDocument file into rows.

    Nothing is kept between calls, so every method is a class method.

    Attributes: FORMATS: The formats that are read, as file extensions without the dot. MAX_BYTES: The largest file read. MAX_ROWS: The most data rows a file may hold. MAX_COLUMNS: The most cells kept of a row. Cells past it are never read. MAX_UNCOMPRESSED: The largest a workbook’s first sheet may be once unpacked. MAX_UNCOMPRESSED_ODS: The largest an OpenDocument spreadsheet’s content may be once unpacked. odfpy builds the whole document in memory at about twenty times the size of the XML, so this is far below MAX_UNCOMPRESSED. MAX_REPEAT: The most empty cells one repeated cell of an OpenDocument row is expanded to.

    FORMATS¶

    (‘csv’, ‘tsv’, ‘xlsx’, ‘ods’)

    MAX_BYTES¶

    None

    MAX_ROWS¶

    50000

    MAX_COLUMNS¶

    1024

    MAX_UNCOMPRESSED¶

    None

    MAX_UNCOMPRESSED_ODS¶

    None

    MAX_REPEAT¶

    1024

    SHEET_ENTRIES¶

    None

    ENCODINGS¶

    (‘utf-8-sig’, ‘cp1252’, ‘latin-1’)

    classmethod file_format(name)[source]¶

    Name the format of a file by its extension.

    Args: name: The file’s name.

    Returns: One of FORMATS.

    Raises: FileProblem: With code format when the extension is not one read.

    classmethod blank(cell)[source]¶

    Say whether a cell holds nothing.

    Args: cell: A cell as read.

    Returns: True for no value or text of only spaces.

    classmethod decode(raw)[source]¶

    Read the bytes of a text file.

    Args: raw: The file’s bytes.

    Returns: The text, read as UTF-8 with or without a byte order mark, then as Windows-1252.

    classmethod too_many_rows()[source]¶

    Build the problem of a file with more rows than the limit.

    Returns: A FileProblem with code too_many_rows.

    classmethod limited(rows)[source]¶

    Pass rows on until one more than the limit has been read.

    Args: rows: An iterable of rows, the first of which holds the headings.

    Yields: Rows up to the headings and MAX_ROWS + 1 rows with a value. Blank rows are passed on so a row keeps its line number, up to twice the limit.

    Raises: FileProblem: With code too_many_rows when the file goes on past the blank rows passed, so rows after them would be left out unseen.

    classmethod trimmed(row)[source]¶

    Cut a row to MAX_COLUMNS cells and drop its empty cells at the end.

    Args: row: A row as read.

    Returns: The row’s cells as a list.

    classmethod check_unpacked(raw, fmt)[source]¶

    Refuse a workbook or spreadsheet whose first sheet unpacks too large.

    The size is read from the archive’s index, so nothing is unpacked.

    Args: raw: The file’s bytes. fmt: xlsx or ods.

    Raises: FileProblem: With code unreadable when the file is not an archive and too_large_unpacked when the sheet is over MAX_UNCOMPRESSED, or MAX_UNCOMPRESSED_ODS for an OpenDocument file.

    classmethod read_csv(raw, fmt)[source]¶

    Read a comma, semicolon or tab separated file.

    Args: raw: The file’s bytes. fmt: csv or tsv. A tab is never the delimiter of a csv.

    Returns: An iterator of rows of text.

    classmethod read_xlsx(raw)[source]¶

    Read the first sheet of an Excel workbook.

    Args: raw: The file’s bytes.

    Returns: An iterator of rows of cells.

    classmethod read_ods(raw)[source]¶

    Read the first sheet of an OpenDocument spreadsheet with odfpy.

    A repeated cell is read once for each repeat, and a repeated row likewise. Repeated empty cells are cut at MAX_REPEAT and a row at MAX_COLUMNS.

    Args: raw: The file’s bytes.

    Returns: An iterator of rows of cells.

    classmethod ods_rows(table_rows)[source]¶

    Expand the repeats of an OpenDocument table’s rows.

    Args: table_rows: The table’s row elements.

    Yields: One list of cells for each row, repeated rows as many times as repeated.

    classmethod ods_cells(table_row)[source]¶

    Read the cells of an OpenDocument row, repeats expanded.

    Args: table_row: The row element.

    Returns: The cells’ values: text, a number, a date as text or None.

    classmethod read_grid(raw, fmt)[source]¶

    Read every row of a file, as lists of cells.

    Reading stops at the headings and MAX_ROWS + 1 rows, so a file over the limit is never read to its end. Each row is cut to MAX_COLUMNS cells with its empty cells at the end dropped as it is read.

    Args: raw: The file’s bytes. fmt: One of FORMATS.

    Returns: The rows, headings first.

    Raises: FileProblem: With code unreadable, too_large_unpacked or too_many_rows. Any error a parser raises while it reads is unreadable.

    classmethod parse(raw, fmt)[source]¶

    Read a file’s headings and its rows.

    Args: raw: The file’s bytes. fmt: One of FORMATS.

    Returns: The headings as trimmed text with empty ones at the end dropped, the rows as lists of cells cut or filled to the headings’ length with blank rows left out, and the line of the file each row came from, counting from 1.

    Raises: FileProblem: With code too_large, unreadable, empty, no_rows or too_many_rows.
