fairdm.contrib.collections.plugins#

The Samples and Measurements tabs of a dataset, a project and a contributor, and a sample’s Measurements tab.

A dataset’s, project’s or contributor’s tab lists the samples or the measurements of one registered type at a time, the most numerous type unless the address names another. A sample’s tab lists every type of measurement made on it at once, one after another.

class StableOrderData(data: django.db.models.QuerySet)#

Bases: django_tables2.data.TableQuerysetData

Table rows whose order always ends in the primary key, so paging never repeats a row.

The order a table applies, by its Meta.order_by or by a column the reader chose, replaces the queryset’s own, and a column that holds equal values leaves ties in no fixed order. Appending pk after every ordering makes each page the same on every request.

order(queryset: django.db.models.QuerySet, is_descending: bool) → tuple[django.db.models.QuerySet, bool]#

Order by the sample’s name, with the samples the viewer may not open last.

Only the rows with an openable sample are ordered by name. The rest sort as one block after them, left to the table’s primary-key tie-break in either direction, so the order reveals neither which measurements share a hidden sample nor where its name would fall.

Args: queryset: The rows to order. is_descending: Whether the reader asked for the descending order.

Returns: The ordered rows, and True to say the column ordered them itself.

records_are_offered(request: django.http.HttpRequest, obj: django.db.models.Model | None) → bool#

Return whether the request’s user is offered the tabs of a dataset, project or contributor.

A dataset’s tabs follow its records (:func:dataset_records_visible). A project’s follow the project’s own page: what its datasets hold is decided row by row, so a project whose records the viewer may not see answers empty rather than 404. A contributor’s follow the contributor’s overview, which opens for everyone.

Args: request: The current request. obj: The dataset, project or contributor, or None when no record has been resolved.

Returns: True when the tabs may be shown.

class RecordsTab(**kwargs)#

Bases: fairdm.contrib.plugins.mixins.PrivateRecordNotFoundMixin, fairdm.contrib.plugins.Plugin, fairdm.contrib.collections.views.DataTableView

The samples or the measurements of a dataset, project or contributor, one type at a time.

A dataset’s tab lists the records in the dataset. A project’s lists the records in any of its datasets, each row naming its dataset. A contributor’s lists the records credited to them or beneath something credited to them (Contributor.get_associated_records), each row naming its dataset.

class SampleMeasurements(**kwargs)#

Bases: fairdm.contrib.plugins.Plugin, django_tables2.views.MultiTableMixin, fairdm.views.FairDMTemplateView

List every measurement made on a sample, one table per type, on one page.

The tables follow one another, so that results from different methods are read together. A measurement is listed when the viewer may see its own dataset, whichever dataset that is and whoever may see the sample. Each table has its type’s columns, leads with the measurement’s name and its dataset, and pages on its own.

Attributes: sections: Each listed type with its table, most numerous first.
