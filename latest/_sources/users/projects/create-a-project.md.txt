# How to create a project

A project groups the datasets that come from one body of research and gives them a shared name, team and set of dates. Create it early, before the data exists, so that your colleagues and other researchers can find the work.

## Before you start

You need to be [signed in](../account/sign-in.md).

## Steps

1. In the header, select **Create new**, then **Project**. On the [Projects](projects.md) screen, the **Add** button does the same. The [Create a project](create-project.md) screen opens.
2. In **Project name**, type the project's full name. Others find the project by this name, so avoid an internal abbreviation.
3. In **Status**, choose the stage the project is at.
4. In **Visibility**, choose **Private** or **Public**. Public is already selected. Choose **Private** if the project should not be seen yet. You can change it later on [Edit details](edit-details.md).
5. Select **Save & continue**.

## The result

You land on the new project's page, and a message says "Project successfully created." The project lists you on its [Contributors](../contributors/contributors-tab.md) tab with the **Can manage** level and the roles Creator, Project Member and Contact Person.

The project is still bare. To finish it:

1. Add an abstract on [Descriptions](../editing-a-record/descriptions.md).
2. Add the project's start and end on [Key dates](../editing-a-record/key-dates.md).
3. Add the project's image and owner organization on [Edit details](edit-details.md).
4. Add its first dataset with [How to create a dataset](../datasets/create-a-dataset.md).

The **Metadata readiness** card on the project page lists what is still missing.
