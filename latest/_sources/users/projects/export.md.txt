# Export Project Data

The Export Project Data screen is the page behind the **Export** tab of a project. Open [the project page](project.md) and choose the **Export** tab. Whoever may open the project may open this tab. See [How access to a record is decided](../../explanation/how-access-to-a-record-is-decided.md).

## What the screen shows

The screen shows its heading, **Export Project Data**, and one line of placeholder text. It has no buttons, no downloads and no form. Nothing on it exports the project's data. The project's name and the Projects screen appear in the breadcrumb trail above the heading.

## Where to get the project's data instead

- The project page has a **REST API** button in its Details card, which opens the project in the API. See [API documentation](../api/api-docs.md).
- A script can read a project and its datasets through the API. The facts about the endpoints are in the [REST API reference](../../developers/reference/rest-api.md).

## What you can do here

Nothing. Return to [the project page](project.md) to work on the project.
