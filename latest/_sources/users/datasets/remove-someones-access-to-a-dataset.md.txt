# How to remove someone's access to a dataset

Removing someone's access takes them off the dataset's list so they can no longer change it or, when the dataset is private, open it. Do it when a collaborator leaves the team or while you review the data.

## Before you start

You need the **Can manage** level on the dataset or on the project above it. Only managers see the controls on the **Contributors** tab. See [How access to a record is decided](../../explanation/how-access-to-a-record-is-decided.md).

## Steps

1. Open [the dataset page](dataset.md) and choose the **Contributors** tab.
2. Find the person under **People**. The badge beside their name shows their level.
3. To take them off the dataset, select **Remove** beside their name. To keep them credited but stop them changing the dataset, select **Edit** instead, choose **Can view** and select **Save**.
4. If you chose **Remove**, read the list on the confirmation screen and select **Remove**.

## The result

A removed person is no longer credited on the dataset or named in its citation. A private dataset no longer opens for them. If you add them again later, they start with **Can view** and no roles.

A person you set to **Can view** stays credited and can still open the dataset, even when it is private.

## If the person can still open the dataset

- They may hold a level on the project above. The **Access from the project** card on the Contributors tab names them, and its **Manage there** button opens the project's tab, where you can change it.
- They may hold a portal role that reaches every dataset, such as Data Curator. A portal administrator changes that.
- The dataset may be public, which opens it to everyone. See [How to restrict a dataset to specific people](restrict-a-dataset-to-specific-people.md).

## If the screen refuses to remove them

A dataset always keeps a manager. When the person is the only one who can manage the dataset, the screen says so and offers no **Remove** button. Give someone else **Can manage** first. An organization cannot be removed while the screen lists people credited from it. Change their organization or remove them first.
