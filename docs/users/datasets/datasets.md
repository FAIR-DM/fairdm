# Datasets

The Datasets screen lists the datasets in the portal as cards, with search, sorting and filters. Open it from **Datasets** in the navigation menu. Anyone can open it, signed in or not, and everyone sees the same list: the datasets whose visibility is Public. A private dataset never appears here, not even for the people who work on it. They reach their private datasets from the dataset's own page. See [How access to a record is decided](../../explanation/how-access-to-a-record-is-decided.md) for the reasoning.

## The toolbar

The toolbar sits above the list and has these controls:

- **Search** matches the dataset's name, its portal ID, the values of its identifiers, the text of its descriptions and its keywords.
- **License** keeps the datasets that carry the licences you choose.
- **Sort** orders the list. The choices are Default order, Date created (newest first), Date created (oldest first), Recently Updated, Name A-Z and Name Z-A. Default order puts the most recently updated dataset first.
- **Filters** opens a panel with the remaining filters.

The panel holds these filters:

- **Has image** keeps the datasets that have a cover image.
- **Project** keeps the datasets that belong to the projects you choose. Everyone is offered the same public projects.
- **Description Type** keeps the datasets that carry a description of the type you enter.
- **Date Type** keeps the datasets that carry a date of the type you enter.

Filters combine, so a dataset must match all of them. Under the toolbar a line gives the number of datasets that match and, when you have chosen a sort, the order the list is in.

The screen has no **Add** button. Start a dataset from the **Create new** menu in the header instead. See [Create a Dataset](create-dataset.md).

## The dataset cards

Each card is one link to the dataset's page. A card shows:

- the dataset's image, or an icon when it has none
- a **Dataset** badge, and a **Published** badge when the dataset's data has been published
- for a published dataset only, the number of samples and measurements it holds, or **No samples** and **No measurements**
- the dataset's name
- the first people credited on it, and the name of its project
- a short piece of the abstract
- the dataset's keywords
- the portal ID, with a button that copies it
- the dataset's licence
- when the dataset was last updated

The list shows 25 datasets to a page, with page links under the last card.

## When the list is empty

With nothing to show, the screen shows the heading **There's nothing here yet** and nothing else.

When a search or filter matches nothing, the heading reads **No datasets match**, with the line "Try other words or fewer filters." and a **Clear all** button.
