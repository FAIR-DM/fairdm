# Descriptions

The descriptions page is where the prose about a measurement is written: a set of labelled areas,
one for each kind of description a measurement supports, such as the conditions it was made under
and how it was set up.

You reach it from the **Manage** menu on the measurement's own page, as **Edit descriptions**.

## Who can open it

Anyone holding permission to change the measurement. Someone who may only view it sees no Manage menu,
and is refused if they type the address. A private measurement does not answer at all to someone who may
not see it, the same rule the measurement's own page applies.

## Writing a description

Each area is optional and holds one passage of text. Fill an area and save to record that
description. Empty an area and save to remove it.

Saving returns you to the measurement's page, where the descriptions are shown.
