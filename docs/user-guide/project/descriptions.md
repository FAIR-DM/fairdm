# Descriptions

The descriptions page is where the prose about a project is written: a set of labelled areas,
one for each kind of description the project supports.

## Who can open it

Anyone holding permission to change the project — typically its contributors. Anyone else is
refused.

## The description types

Each area is optional, and each holds at most one passage of text:

- **Abstract** — a brief summary of the project.
- **Introduction** — an introduction to the project's subject.
- **Background** — the context the project sits within.
- **Objectives** — what the project sets out to achieve.
- **Expected output** — what the project expects to produce.
- **Conclusions** — what the project found or concluded.
- **Other** — anything that doesn't belong in the areas above.

Leaving an area empty removes any description of that type already saved against the project;
filling it in saves or replaces the description of that type. There is no limit on how many
times you can come back and revise what's written here.
