# Descriptions

The descriptions page is where the prose about a sample is written: a set of labelled areas, one
for each kind of description a sample supports, such as how it was collected, prepared and stored.

You reach it from the **Manage** menu on the sample's own page, as **Edit descriptions**.

## Who can open it

Anyone holding permission to change the sample. Someone who may only view it sees no Manage menu,
and is refused if they type the address. A private sample does not answer at all to someone who may
not see it, the same rule the sample's own page applies.

## Writing a description

Each area is optional and holds one passage of text. Fill an area and save to record that
description. Empty an area and save to remove it.

Saving returns you to the sample's page, where the descriptions are shown.
