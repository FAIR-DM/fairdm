# Key dates

The key dates page records the dates that matter in a sample's life, such as when it was collected and when it
was prepared.

You reach it from the **Manage** menu on the sample's own page, as **Key dates**.

## Who can open it

Anyone holding permission to change the sample. Someone who may only view it sees no Manage menu, and
is refused if they type the address. A private sample does not answer at all to someone who may not
see it, the same rule the sample's own page applies.

## Recording a date

The page is a table with one row per date. Each row pairs a date type with a date. Add a row to
record a date, change either part of a row to correct it, and remove a row to delete it. Each date
type can be used once.

A date can be as precise as you know it. Enter a year alone, a year and a month, or a full date,
and the sample's page shows it exactly as precisely as you entered it.

Saving returns you to the sample's page, where the dates are listed.
